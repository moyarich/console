## Inherited color scheme

Set the standard `color-scheme` property on a host container when multiple console surfaces should inherit the same appearance. Built-in colors use `light-dark()`, so `light`, `dark`, and `light dark` work without a `prefers-color-scheme` media query. The portaled context menu preserves the computed scheme.
