import source from "./example.tsx?raw";

`createResizableConsoleAddon()` manages resize state and pointer interactions. The addon controls resize directions, size constraints, resize-edge placement, visible grips, and the public resize theme variables.

Choose a resize direction, then drag the visible handle along the console shell. The addon supports horizontal, vertical, both, block, and inline resize directions.

This example also uses the core panel sizing theme variables so the console starts at a smaller initial size.

- `--console-panel-width`
- `--console-panel-height`
- `--console-panel-min-width`
- `--console-panel-min-height`
