---
label: "Core Addon - Data export"
description: "Export logical console data as text or structured JSON, similar to copying an object, without turning export into a diagnostics feature."
---

<Playground />

Open each console's action menu to copy the logical view as JSON or download text/JSON. The addon is additive, so existing core actions remain available.

Structured mode exports the underlying `ConsoleMessageData`. ANSI mode exports the resolved logical process view after carriage-return normalization and process-output processors.
