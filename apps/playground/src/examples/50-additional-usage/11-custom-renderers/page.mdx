Renderers are tried in order and may opt out by returning `undefined`. In this example, the metric renderer handles the bundle-size badge but deliberately returns `undefined` for the modules metric, so that value falls back to the built-in inspector.

Messages that do not match the custom message renderer also continue through the built-in renderer.
