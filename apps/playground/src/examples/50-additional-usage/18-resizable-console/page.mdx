`createResizableConsoleAddon()` owns the resize state and pointer handling. The addon imports its own stylesheet, which owns resize directions, size constraints, edge placement, visible grips, and the public resize theme variables. The core `Console` package likewise imports its own stylesheet; core contains no resize-specific CSS and only exposes the generic frame-decorator extension point used by the addon.

Choose a resize direction, then drag the visible handle around the console shell. Horizontal, vertical, both, block, and inline directions are supported.

The example also uses the core panel sizing theme inputs `--console-panel-width`, `--console-panel-height`, `--console-panel-min-width`, and `--console-panel-min-height` instead of hard-coded React layout properties.
