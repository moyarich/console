`createResizableConsoleAddon()` owns the resize state, pointer handling, size constraints, and visible grips. The core `Console` only renders its normal frame and exposes the generic frame-decorator extension point used by the addon.

Choose a resize direction, then drag the visible handle around the console shell. Horizontal, vertical, both, block, and inline directions are supported.
