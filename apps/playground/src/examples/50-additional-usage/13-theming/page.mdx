label: "Theming"
description: "Theme the panel, output surface, icons, native color-scheme, and portaled context menu with inheritable --console-* CSS variables."
---

<Playground />

Token suffixes match the CSS property they control. Border tokens such as `--console-panel-border` accept a complete border shorthand, while color-only overrides end in `-color`.

The `--console-color-scheme` and `--console-context-menu-color-scheme` tokens also let native scrollbars and the portaled context menu follow the selected theme.
