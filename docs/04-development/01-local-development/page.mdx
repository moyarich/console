# Local development

Install dependencies from the repository root:

```sh
npm ci --include=optional
```

Run the Vite documentation playground:

```sh
npm run dev
```

The private playground lives under:

```text
apps/playground/
```

It renders MDX documentation and examples from outside the app directory:

```text
docs/
├── 03-reference/
├── 04-development/
└── examples/
```

Build the playground:

```sh
npm run build:playground
```

Build all publishable packages and the playground:

```sh
npm run build
```

Publishable packages use package-local Vite library configs. Vite produces the ESM/CommonJS JavaScript outputs, and TypeScript emits declaration files into each package's `dist/*` directory.

Vitest remains the repository test runner.

The playground is a repository development/documentation surface and is never published as a package.
