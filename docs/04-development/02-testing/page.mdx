# Testing

Console uses **Vitest** for its test suite.

Run the complete test suite:

```sh
npm test
```

Run tests in watch mode:

```sh
npm run test:watch
```

Run TypeScript validation:

```sh
npm run typecheck
```

Run lint and formatting checks:

```sh
npm run lint
npm run format:check
```

Build the Vite playground and publishable packages:

```sh
npm run build
```

Each publishable workspace runs its own `vite build` before declaration generation.

Validate the package archives:

```sh
npm run pack:packages
```

CI runs the same lint, formatting, typecheck, Vitest, build, Storybook, and package-archive checks before changes are merged.

## Self-healing checks

Feature-branch pushes run repository-local repair workflows:

- **Self-heal formatting** runs Prettier, verifies formatting, and commits the repair when files changed.
- **Self-heal package lock** recreates and validates `package-lock.json` when workspace manifests change, then commits the repaired lockfile.

Bot-generated repair commits are ignored by the self-healers to prevent workflow loops.

CI remains authoritative: lint, formatting, typecheck, Vitest, builds, Storybook, and package archive checks must still pass after any repair commit.
