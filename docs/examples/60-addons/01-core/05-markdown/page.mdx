The Markdown addon is designed for output you do not control. A producer can emit a Markdown document as an ordinary string:

```ts
console.log(GITHUB_STEP_SUMMARY);
```

The addon parses each complete string value and only takes over when the Markdown AST contains syntax beyond plain paragraphs, text, and line breaks. Bare URLs stay on the normal console rendering path.

The example mirrors a GitHub Actions `$GITHUB_STEP_SUMMARY` containing headings, a table, inline code, and a list, followed by an ordinary multiline log message.
