# @moyarich/console

`@moyarich/console` is a React console toolkit for capturing, transporting, and rendering structured console messages and process output.

## Documentation

- Browse runnable examples under **Examples**.
- Browse the public package API under **API**.
- Browse repository setup and testing guidance under **Development**.

The GitHub Pages site is rendered by the private Vite app in `apps/playground`. Repository-level contributor material stays under `docs/*`; each publishable package owns its public docs and examples under its own `packages/*/docs` directory.
