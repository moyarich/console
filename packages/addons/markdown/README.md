# @moyarich/console-addon-markdown

Render recognized Markdown in structured console values.

GitHub Flavored Markdown output for Markdown strings; plain text stays unchanged.

## Installation

```bash
npm install @moyarich/console @moyarich/console-addon-markdown
```

## Using the addon

The package exports `createConsoleMarkdownAddon()`, which creates an optional addon for the Console `addons` prop. Addons can be enabled independently; Console does not require this package to render output.

For runnable examples and available options, see the [package examples](./examples) and the [interactive documentation](https://moyarich.github.io/console/). See the [changelog](./CHANGELOG.md) for version-specific changes.
