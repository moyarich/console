# @moyarich/console-addon-resizable

Add resizing to a React Console by passing a `createResizableConsoleAddon` instance to its `addons` prop. The example defines its own messages, sizing constraints, direction control, and handle theme.

import source from "./example.tsx?raw";

<RunnableExample source={source} sourcePath="example.tsx" />

`createResizableConsoleAddon()` manages resize state and pointer interactions. The addon controls resize directions, size constraints, resize-edge placement, visible grips, and the public resize theme variables.

Choose a resize direction, then drag the visible handle along the console shell. The addon supports horizontal, vertical, both, block, and inline resize directions.

The resizable frame resolves its color scheme in this order:

1. `--console-resize-color-scheme`
2. `--console-panel-color-scheme`
3. `--console-color-scheme`
4. the inherited standard `color-scheme` property

The playground owns the **System / Light / Dark** theme control globally through the standard `color-scheme` property. This example uses `light-dark()` for its resize-handle tokens, so the handles follow the playground color scheme without maintaining separate theme state.

The example also uses the core panel sizing theme variables so the console starts at a smaller initial size.

- `--console-panel-width`
- `--console-panel-height`
- `--console-panel-min-width`
- `--console-panel-min-height`

## Setup and options

Create the addon with `useMemo` so React renders keep the same instance until its configuration changes. The Console activates the addon and cleans it up when it is removed or unmounted. Import the Console stylesheet; importing the addon loads its resize stylesheet automatically.

| Option                            | Default       | Purpose                                                                                |
| --------------------------------- | ------------- | -------------------------------------------------------------------------------------- |
| `direction`                       | `"both"`      | Resize horizontally, vertically, on both axes, or along logical `block`/`inline` axes. |
| `defaultWidth` / `defaultHeight`  | `720` / `300` | Initial dimensions; accepts numbers or CSS size strings.                               |
| `minWidth` / `minHeight`          | `320` / `180` | Minimum dimensions while dragging, in pixels.                                          |
| `maxWidth` / `maxHeight`          | Unset         | Optional drag limits in pixels; horizontal resizing also respects the parent width.    |
| `horizontalEdge` / `verticalEdge` | `"end"`       | Place each handle on its physical `"start"` or `"end"` edge.                           |
| `onResize`                        | Unset         | Receive `{ width, height }` whenever a drag updates the frame size.                    |
| `className` / `style`             | Unset         | Style the addon-owned frame and override resize theme variables.                       |

The addon owns the resizable frame and pointer handling. The Console continues to own the panel and output viewport; no separate core manager is needed.
