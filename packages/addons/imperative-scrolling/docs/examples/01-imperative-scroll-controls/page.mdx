The imperative API and the imperative-scrolling addon consume the same core viewport service.

Use the buttons to call `ConsoleHandle` methods directly; the console action menu exposes top, latest-output, and focus actions from the addon.

<RunnableExample source={source} sourcePath="example.tsx" />

## Configure viewport actions

See the [API reference](#/addons/imperative-scrolling/reference/scrolling) for the contract and options.

```tsx
import { Console } from "@moyarich/console";
import { createImperativeScrollingAddon } from "@moyarich/console-addon-imperative-scrolling";

<Console messages={messages} addons={[createImperativeScrollingAddon()]} />;
```
