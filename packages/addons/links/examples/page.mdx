# Web links

Automatic web links are provided by `@moyarich/console-addon-links` instead of Console core. The addon registers a low-priority `linkProvider` extension, so direct host providers take precedence for overlapping ranges.

Remove this addon from `addons` or add its ID to `disabledAddonIds` to render URLs as ordinary text. Both structured and terminal modes are supported.
