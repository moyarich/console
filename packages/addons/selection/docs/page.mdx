# @moyarich/console-addon-selection

Adds semantic output selection without replacing native text selection.

The controller stores stable selected IDs separately from source messages/output. Filtering may hide selected entries, but does not clear selection.

Structured messages receive a default selected-state decoration and toggle action. Terminal/process entry IDs can be selected through the same headless controller.
