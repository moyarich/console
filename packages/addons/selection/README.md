# @moyarich/console-addon-selection

Select structured and terminal messages.

Stable-ID selection, selectable ranges, and optional message decorations.

## Installation

```bash
npm install @moyarich/console @moyarich/console-addon-selection
```

## Using the addon

The package exports `createConsoleSelectionAddon()`, which creates an optional addon for the Console `addons` prop. Addons can be enabled independently; Console does not require this package to render output.

For runnable examples and available options, see the [package examples](./examples) and the [interactive documentation](https://moyarich.github.io/console/). See the [changelog](./CHANGELOG.md) for version-specific changes.
