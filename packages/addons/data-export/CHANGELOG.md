# Changelog

## 0.2.0

### Changed
- Added localization coverage for export controls across supported languages, including Portuguese.
- Updated the required `@moyarich/console-core` peer dependency to `^0.2.0`.

## 0.1.0

### Added

- Export structured console messages and terminal output as readable plain text or structured JSON.
- Export either all retained entries or only currently visible entries, including filtered results.
- Copy JSON data to the clipboard or download text and JSON files using built-in panel and context actions.
- Include message metadata, serialized values, timestamps, and process stream information in structured exports.
- Configure export actions, their scope, and download filenames.
