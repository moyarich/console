# Typewriter

Progressive reveal of already-rendered interactive content. The animation wraps each rendered entry without replacing links, structured values, or custom renderers.

import source from "./example.tsx?raw";

<RunnableExample source={source} sourcePath="example.tsx" />

Typewriter progressively reveals the existing rendered entry using clipping; it does not reconstruct text character-by-character. The addon respects reduced-motion preferences.
