# Typewriter

Character-by-character typing across rendered text nodes. The animation wraps each rendered entry without replacing links, structured values, or custom renderers.

Typewriter reveals characters one by one, including text inside links and ANSI spans, while keeping the existing rendered elements and interactive behavior. Use a longer duration to make the keystrokes visible. The addon respects reduced-motion preferences.
