# Animated output

The animation addon decorates each fully rendered entry, preserving links, ANSI formatting, expandable objects, and custom renderers. Animations respect `prefers-reduced-motion` and completed entries with stable IDs do not replay during normal rerenders.

Explore each effect in its own editable, runnable example:

- [Fade](#/package-addons-animation/fade) — opacity reveal.
- [Slide](#/package-addons-animation/slide) — vertical entrance.
- [Fade + slide](#/package-addons-animation/fade-slide) — combines opacity and motion.
- [Typewriter](#/package-addons-animation/typewriter) — progressively reveals the already-rendered entry without rebuilding its text.
- [Stagger and wait](#/package-addons-animation/stagger-and-wait) — delay and sequence multiple entries.

Use `createConsoleAnimationAddon({ effect: "fade-slide", duration: 0.3, stagger: 0.05, wait: 0 })` with the Console `addons` prop. Timing values are in seconds.
