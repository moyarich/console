# Stagger and wait

Sequenced entries with an initial delay. The animation wraps each rendered entry without replacing links, structured values, or custom renderers.

import source from "./example.tsx?raw";

<RunnableExample source={source} sourcePath="example.tsx" />

With `sequence: true`, each entry waits until the previous one completes. `wait` delays the first entry; `stagger` adds a pause between completed entries. The addon respects reduced-motion preferences.
