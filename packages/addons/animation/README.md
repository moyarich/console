# @moyarich/console-addon-animation

Animate incoming structured and terminal entries.

Fade, slide, reveal, and sequenced animations without replacing the original output renderer.

## Installation

```bash
npm install @moyarich/console @moyarich/console-addon-animation
```

## Using the addon

The package exports `createConsoleAnimationAddon()`, which creates an optional addon for the Console `addons` prop. Addons can be enabled independently; Console does not require this package to render output.

For runnable examples and available options, see the [package examples](./examples) and the [interactive documentation](https://moyarich.github.io/console/). See the [changelog](./CHANGELOG.md) for version-specific changes.
