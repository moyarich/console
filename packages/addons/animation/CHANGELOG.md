# Changelog

## 0.2.0

### Changed

- Requires `@moyarich/console-core` version `0.2.x` (peer dependency `^0.2.0`); applications using `0.1.x` must upgrade the host package alongside this addon.

## 0.1.0

### Added

- Animate newly rendered structured Console and terminal entries with fade, slide, combined fade-slide, and progressive reveal effects.
- Sequence animated entries and configure their delays.
- Preserve the underlying link, ANSI, and value renderers while animations are active.
