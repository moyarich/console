# Changelog

## 0.2.0

### Changed

- Updated the required peer dependency range for `@moyarich/console-core` and `@moyarich/console` from `^0.1.0` to `^0.2.0`.
- No separate user-facing feature or behavior change is identified for this addon in this version.

## 0.1.0

### Added

- Optional feed-style structured output renderer using the existing output-renderer extension point.
- Severity labeling and accessible message text, while retaining source messages without modification.
