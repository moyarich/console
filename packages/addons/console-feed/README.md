# @moyarich/console-addon-console-feed

Render structured Console messages in a feed layout.

Severity labels and accessible message text without changing the source messages.

## Installation

```bash
npm install @moyarich/console @moyarich/console-addon-console-feed
```

## Using the addon

The package exports `createConsoleFeedAddon()`, which creates an optional addon for the Console `addons` prop. Addons can be enabled independently; Console does not require this package to render output.

For runnable examples and available options, see the [package examples](./examples) and the [interactive documentation](https://moyarich.github.io/console/). See the [changelog](./CHANGELOG.md) for version-specific changes.
