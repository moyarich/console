## 0.1.0

### Added

- Filter console messages by method, source, and case-insensitive text search.
- Search message values, methods, and sources, including searchable text contributed by extensions.
- Use ready-made filtering controls or a headless controller for custom host interfaces.
- Enable or disable individual methods, select sources, reset filters, and observe filtering state changes.
- Discover source choices from retained messages when explicit source options are not supplied.
