# Changelog

## 0.1.0

### Added

- Inspect structured console messages and terminal-output processing through JSON diagnostic reports.
- Compare all retained entries with currently visible entries, including their respective counts.
- For terminal output, include raw input and normalized and processed output so transformations can be inspected.
- Capture message details, stream metadata, and serializable structured values in diagnostic reports.
- Copy or download reports as JSON using configurable panel and context actions.
