# Save and restore sessions

Use `createConsoleSessionAddon()` to capture retained logical data from the Console service and serialize it to JSON. Restore the snapshot to host-owned state; loading a session never changes the source messages implicitly.

Snapshots include version metadata and an optional dropped-history counter. The parser rejects unsupported versions and malformed records. Hosts can save JSON to local storage, a server, or a bug-report bundle according to their privacy policy.
