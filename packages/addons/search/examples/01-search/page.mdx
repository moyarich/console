# Search and match navigation

The optional `@moyarich/console-addon-search` contributes a search field, case-sensitivity, whole-word and regex settings, result counts, highlighted matching rows, and next/previous navigation. Use **F3** and **Shift+F3** to navigate when the Console has keyboard focus.

The controller searches the logical, filtered data snapshot rather than mounted DOM rows, so results survive filtered views and virtualization. Clearing the query removes highlighting. Search does not change source messages.
