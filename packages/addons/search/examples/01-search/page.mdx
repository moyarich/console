# Search and match navigation

The optional `@moyarich/console-addon-search` contributes a search field, case-sensitivity, whole-word and regex settings, result counts, highlighted matching rows, and next/previous navigation. Use **F3** and **Shift+F3** to navigate when the Console has keyboard focus.

The controller searches the logical, filtered data snapshot rather than mounted DOM rows, so results survive filtered views and virtualization. Clearing the query removes highlighting. Search does not change source messages.

## Inline highlights

Search results are marked directly in rendered string values, including nested object strings and ANSI terminal lines. Highlighting is presentation-only: it does not rewrite messages, interfere with links, remove ANSI styles, or affect the logical search results used for next/previous navigation. Clearing the query removes the marks. For non-text structured data, the message's match badge remains available.

Set the parent Console theme's `--console-search-highlight-background-color`, `--console-search-highlight-color`, and `--console-search-highlight-active-color` variables to customize the inline marks.

## Theming

Search controls inherit the surrounding Console theme and expose public CSS custom properties for targeted overrides. These resolve to private `--_console-search-*` component variables.

```css
.my-console {
  --console-search-background-color: #151b2b;
  --console-search-color: #eef2ff;
  --console-search-border-color: #667085;
  --console-search-focus-color: #a5b4fc;
  --console-search-highlight-background-color: #fde68a;
  --console-search-highlight-color: #312e09;
  --console-search-highlight-active-color: #818cf8;
}
```

Use `color-scheme: dark` or `color-scheme: light` on the theme wrapper to select the built-in search highlight defaults.
