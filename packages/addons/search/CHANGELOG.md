# Changelog

## 0.2.0

### Changed

- Updated the required peer dependency range for `@moyarich/console-core` from `^0.1.0` to `^0.2.0`.
- No separate user-facing feature or behavior change is identified for this addon in this version.

## 0.1.0

### Added

- Search Console output through a headless, observable controller and optional built-in controls.
- Find text matches with configurable case sensitivity, whole-word matching, and regular expressions.
- Navigate forward and backward between matches, including repeated occurrences within an entry.
- Highlight matches inline and expose search state through a registered service.
