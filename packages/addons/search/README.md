# @moyarich/console-addon-search

Search output and navigate matches.

Search controls, matching options, match highlighting, and navigation.

## Installation

```bash
npm install @moyarich/console @moyarich/console-addon-search
```

## Using the addon

The package exports `createConsoleSearchAddon()`, which creates an optional addon for the Console `addons` prop. Addons can be enabled independently; Console does not require this package to render output.

For runnable examples and available options, see the [package examples](./examples) and the [interactive documentation](https://moyarich.github.io/console/). See the [changelog](./CHANGELOG.md) for version-specific changes.
