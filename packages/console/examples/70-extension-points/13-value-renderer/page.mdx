## Component configuration

Use `valueRenderers` on `<Console>` for host-owned value rendering, or register `consoleExtensionPoints.valueRenderer` for reusable addon behavior. Both customize individual values while retaining the surrounding message.

`getConsoleValueType(value)` returns the discriminator used by a value renderer's `type` field. Renderer callbacks receive readonly context and can call `renderDefault()` to retain built-in behavior. Return `undefined` to allow fallback.
