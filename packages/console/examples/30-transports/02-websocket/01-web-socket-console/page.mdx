## Receiving options and cleanup

`listenForConsoleWebSocket` requires `socket` and `events`; `channel` defaults to `"default"`. It accepts JSON text, ignores invalid JSON and unrelated envelopes/channels, and deserializes accepted events into the emitter. The returned function removes the message listener; it does not close the socket.
