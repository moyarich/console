# Configurable value display

Use `valueDisplay="structured"` (the default) to inspect interactive objects and arrays, or `valueDisplay="string"` to show safe JSON-like text without modifying the original message values.

Changing the select changes the display strategy for existing messages without recapturing their data. Multiple arguments remain separate; plain strings have no extra quotes. Circular references render safely as `[Circular]`. Custom value renderers still take precedence. `console.table()` retains its table layout.
