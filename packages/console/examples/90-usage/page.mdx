Start with [Plain messages](#/package-console/usage/plain-messages) when your application already owns structured message data. Use [React message state](#/package-console/events/react-hooks/message-state) when you need a console-compatible producer and React-managed history. For process stdout/stderr, use [Terminal output](#/package-console/ansi/terminal).

Keep runtime selectors, restart buttons, and application controls around the Console. The component owns the output surface and its panel controls.

## Navigate and style the component

- [Viewport controls](#/package-console/usage/viewport-controls) — scroll, jump to a message, focus, and follow new output.
- [Theming](#/package-console/usage/theming) — configure color schemes and public theme tokens.
- [Extension points](#/package-console/extension-points) — customize rendering, links, filtering, and actions through component props or addons.

Each topic keeps its working source, relevant options, defaults, and behavior together. Start with the example, then adjust its inputs for your application.
