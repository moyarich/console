# High-volume output accessibility

The output retains `role="log"` and an accessible name in both console and terminal modes. **Announcements default to `off`** so appending hundreds of lines does not overwhelm screen-reader users. Entries remain readable by navigating into the output.

## Recommended behavior

- For bulk output and log replay, use `announcementMode="off"` and provide a separate, concise status message outside the log when user attention is needed.
- For occasional updates, opt into `announcementMode="polite"`. The log announces additions, not every text mutation.
- Reserve `announcementMode="assertive"` for exceptional critical use. It may interrupt screen-reader speech.
- Use `outputLabel` when the page has multiple Console instances so each output region is recognizable.
- Preserve keyboard focus when adding, clearing, filtering or navigating output. Do not force focus into the log on every new entry. Use the Context Menu key or Shift+F10 when the console has focus to open its action menu; Escape returns focus to the opener.
- Honor `prefers-reduced-motion` for animated addons, and check text/background contrast and focus indicators in both themes.

Verify the controls and keyboard/focus behavior with browser-based accessibility tests and a screen reader, especially during continuous streaming.
