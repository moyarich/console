# High-volume output accessibility

The output retains `role="log"` and an accessible name in both console and terminal modes. **Announcements default to `off`** so appending hundreds of lines does not overwhelm screen-reader users. Entries remain readable by navigating into the output.

## Recommended behavior

- For bulk output and log replay, use `announcementMode="off"` and provide a separate, concise status message outside the log when user attention is needed.
- For occasional updates, opt into `announcementMode="polite"`. The log announces additions, not every text mutation.
- Reserve `announcementMode="assertive"` for exceptional critical use. It may interrupt screen-reader speech.
- Use `outputLabel` when the page has multiple Console instances so each output region is recognizable.
- Preserve keyboard focus when adding, clearing, filtering or navigating output. Do not force focus into the log on every new entry. Use the Context Menu key or Shift+F10 when the console has focus to open its action menu; Escape returns focus to the opener.
- Honor `prefers-reduced-motion` for animated addons, and check text/background contrast and focus indicators in both themes.

Verify the controls and keyboard/focus behavior with browser-based accessibility tests and a screen reader, especially during continuous streaming.

## Contrast and reduced motion

For custom themes and addons, check normal-size text against its background at **4.5:1** or better, large text at **3:1**, and the visible boundaries of controls and focus indicators at **3:1**. Check both light and dark schemes, including highlighted search results, severity badges, decorations, disabled states, and keyboard focus rings. Do not rely on color alone to distinguish warnings or status.

Animated output uses `prefers-reduced-motion` to skip animated reveal delays and typewriter effects. The resizable addon disables grip/handle transitions under the same media query. Recheck any host-provided animation and theme overrides separately.

## Manual verification checklist

- Use Tab, Shift+Tab, arrow keys, Home, End, Context Menu, Shift+F10, Escape, and Enter through the search, filtering, navigation, panel, and message action controls.
- Verify Escape and choosing an action return focus to the invoker when it still exists. Repeat after filtering or virtualizing rows.
- With a screen reader, inspect bulk output with announcements off; then test occasional polite announcements without enabling assertive announcements during large streams.
- Check both themes at 200% zoom and with forced colors where supported, including search highlights and custom decorations.
- Enable reduced motion and verify that animated output and resize indicators do not require watching movement to understand state.
