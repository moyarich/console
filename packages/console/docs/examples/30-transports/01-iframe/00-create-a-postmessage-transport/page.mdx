label: "Create a postMessage transport"
description: "Usage example for create a postmessage transport."
---

See the [API reference](#/package-console/reference/transport) for the contract and options.

```ts
const events = createConsoleEventEmitter();

const stopListening = listenForConsolePostMessages({
  events,
  channel: "preview",
  source: iframe.contentWindow,
  origin: "https://preview.example.com",
});
```
