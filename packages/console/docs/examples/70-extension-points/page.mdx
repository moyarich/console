Each extension point has an overview page and separate example pages.

- [processControlParser](#/examples/extension-points/process-control-parser) — Parse stateful semantic controls from raw process chunks before carriage-return and newline normalization.
- [processOutputProcessor](#/examples/extension-points/process-output-processor) — Transform resolved ANSI/process output before the console renders it.
- [structuredOutputParser](#/examples/extension-points/structured-output-parser) — Recognize structured values embedded in terminal text.
- [linkProvider](#/examples/extension-points/link-provider) — Detect application-specific links and attach custom actions to them.
- [outputRenderer](#/examples/extension-points/output-renderer) — Replace the complete output surface for a matching console mode.
- [frameDecorator](#/examples/extension-points/frame-decorator) — Structurally wrap the complete Console frame. Reserve this for frame-level behavior such as resizing or docking.
- [emptyStateRenderer](#/examples/extension-points/empty-state-renderer) — Customize only the empty-state surface while leaving normal output rendering unchanged.
- [panelElement](#/examples/extension-points/panel-element) — Add persistent addon-owned UI to a generic panel placement without wrapping the Console frame.
- [messageFilter](#/examples/extension-points/message-filter) — Contribute a predicate to the structured-message view. Multiple addon filters compose with the host-owned `filter` prop.
- [messageRenderer](#/examples/extension-points/message-renderer) — Customize individual structured message rows.
- [messageDecoration](#/examples/extension-points/message-decoration) — Add UI around a structured row without replacing its renderer.
- [messageTextProvider](#/examples/extension-points/message-text-provider) — Contribute logical searchable/plain text for a structured message without changing its visible renderer.
- [valueRenderer](#/examples/extension-points/value-renderer) — Customize individual structured values while leaving the rest of the message rendering intact.
- [keyboardShortcut](#/examples/extension-points/keyboard-shortcut) — Register a keyboard command scoped to the focused Console instead of installing global document listeners.
- [panelAction](#/examples/extension-points/panel-action) — Add a host-defined action to the console panel actions.
- [contextMenuAction](#/examples/extension-points/context-menu-action) — Add an action to the context menu and inspect the selected target kind.
- [messageAction](#/examples/extension-points/message-action) — Add an action scoped to an individual structured message.
