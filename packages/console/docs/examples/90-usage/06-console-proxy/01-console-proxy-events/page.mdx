---
label: "Console proxy events"
description: "Usage example for console proxy events."
---

See the [API reference](#/package-console/reference/console-proxy) for the contract and options.

```ts
const events = createConsoleEventEmitter();

const runtimeConsole = createConsoleProxy({
  events,
  source: "sandbox",
});

events.on("message", (message) => {
  // store, render, or transport the message
});

runtimeConsole.log("hello", { from: "sandbox" });
runtimeConsole.warn("warning");
```
