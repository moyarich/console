---
label: "Capture outside React"
description: "Usage example for capture outside react."
---

See the [API reference](#/package-console/reference/capture-console) for the contract and options.

```ts
const events = createConsoleEventEmitter();

const restore = captureConsole({
  events,
  consoleTarget: previewConsole,
  source: "preview",
  passThrough: true,
});

// later
restore();
```
