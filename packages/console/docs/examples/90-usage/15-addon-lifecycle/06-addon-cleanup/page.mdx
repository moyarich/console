---
label: "Addon cleanup"
description: "Usage example for addon cleanup."
---

See the [API reference](#/package-console/reference/addons/overview) for the contract and options.

```ts
activate(host) {
  const controller = new AbortController();

  host.scope.defer(() => {
    controller.abort();
  });

  return () => {
    // Optional additional addon cleanup.
  };
}
```
