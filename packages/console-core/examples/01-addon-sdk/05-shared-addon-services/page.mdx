## Service lookup

`createConsoleServiceToken(id)` identifies one typed service. `provide(token, service)` returns a disposable; `get(token)` returns a service or `undefined`; `require(token)` throws when unavailable. A headless host can create an independent registry with `createConsoleServiceRegistry`.

The React Console provides `consoleServices.data` and `consoleServices.viewport`. Use capabilities to test optional host functionality: `consoleCapabilities` includes `react`, `dom`, `structuredMessages`, and `processOutput`. Custom hosts can define capabilities with `createConsoleCapability` and build their registry with `createConsoleCapabilityRegistry`.
