## Manager and scope behavior

`createConsoleAddonManager` accepts optional `version` and `capabilities`. Version defaults to `CONSOLE_ADDON_API_VERSION` (`"1"`). `load(addon)` returns a disposable; `unload(id)` reports whether an active addon was removed; `has(id)` checks active IDs. Disposing the manager unloads its addons.

An addon may return a cleanup function, a disposable, or nothing from `activate`. The host owns the activation scope and releases scoped registrations on unload. A standalone `createConsoleDisposableScope` provides `add(disposable)` and `defer(cleanup)`; disposal runs cleanup in reverse order once.
