## Registration and ordering

`createConsoleExtensionPoint(id, composition)` creates a typed token; composition defaults to `"collect"`. The host must read and consume its contributions. `manager.extensions.register(point, contribution, options)` returns a disposable. Optional registration `id` and `priority` control identification and ordering; higher priority resolves first, with registration order breaking ties. `getAll(point)` returns contributions in that order.

A headless host can also create an independent registry with `createConsoleExtensionRegistry`. In an addon, register through `host.extensions` so unload removes its contributions automatically.
